### *Consensus* (Wikipedia editor tool)
<details>
<summary>Click</summary>
 
Consensus is a Manifest V3 browser extension and optional Node.js/TypeScript + MariaDB backend that helps Wikipedia editors and researchers detect factual discrepancies, citation imbalances, outdated claims, and non-neutral (emotional) framing across multiple language editions of Wikipedia, and jump straight to the exact passage to inspect or edit it. Developed during the Junction 2026 Hackathon in 72 hours. Check it out [here](https://github.com/remeseeli/Consensus).

</details>
